Architectural Flow

  1. Step 1: User enters parameters in Angular 18 UI generated from JSON Schema.
  2. Step 2: Angular sends POST /api/reports to Java 17/Spring Boot middleware.
  3. Step 3: Spring Boot inserts report_requests with status PENDING into PostgreSQL.
  4. Step 4: Spring Boot dispatches POST /render to C++ microservice (port 8081).
  5. Step 5: C++ renderer constructs binary PDF/Excel stream and returns byte payload.
  6. Step 6: Spring Boot stores binary data in report_outputs and marks status DONE.
  7. Step 7: User downloads binary output directly via GET /api/reports/{id}/output.
